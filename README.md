# JianjiaOS

个人自用的 Android 应用外壳：Capacitor + React + TypeScript。

## 开源致谢

本项目用到了以下开源项目：

- [blessonism/grok-icon-study](https://github.com/blessonism/grok-icon-study) — 主页机器人的角色引擎（`src/components/grok-bot/vendor/`）
- [Remix-Design/RemixIcon](https://github.com/Remix-Design/RemixIcon) — 界面图标（`src/assets/icons/`）
- [Ajaxy/telegram-tt](https://github.com/Ajaxy/telegram-tt) — 设计 token 数值、聊天背景渐变与图案（`src/styles/tokens.css`、`src/assets/backgrounds/`）
- [facebook/react](https://github.com/facebook/react) — UI 框架
- [pmndrs/zustand](https://github.com/pmndrs/zustand) — 状态管理
- [ionic-team/capacitor](https://github.com/ionic-team/capacitor) — Web ↔ 原生桥，含 app / browser / preferences / android / cli
- [vitejs/vite](https://github.com/vitejs/vite) — 构建工具
- [vitejs/vite-plugin-react](https://github.com/vitejs/vite-plugin-react) — Vite 的 React 插件
- [pd4d10/vite-plugin-svgr](https://github.com/pd4d10/vite-plugin-svgr) — 将 SVG 导入为 React 组件
- [microsoft/TypeScript](https://github.com/microsoft/TypeScript) — 类型检查
- [oxc-project/oxc](https://github.com/oxc-project/oxc) — oxlint
- [DefinitelyTyped/DefinitelyTyped](https://github.com/DefinitelyTyped/DefinitelyTyped) — `@types/*` 类型声明
